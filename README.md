# Raheel Optics

Standalone Android + Supabase optical order manager cloned from Daymark's offline-first foundation.

```sh
JAVA_HOME=/home/saad/jdk ./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Application ID: `pk.raheeloptics.orders`. Use a separate Supabase project from Daymark.
